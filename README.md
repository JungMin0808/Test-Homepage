# 월드스키 카운터 계산기

태블릿에서 사용할 수 있는 웹 기반 계산기로, 카운터 직원이 손님과 대면하거나 전화 상담 중 빠르게 요금을 산출할 수 있도록 설계했습니다.

## 사용 방법
1. **서버 실행**
   ```bash
   npm install
   npm start
   ```
   기본 포트는 `4000`이며, `PORT` 환경 변수를 설정해 변경할 수 있습니다.
2. 브라우저(크롬, 엣지 등)에서 `http://localhost:4000` 접속 후 바로 사용할 수 있습니다.
3. 상단의 **비수기 / 성수기** 버튼으로 시즌을 전환합니다.
4. 오늘 날짜를 기준으로 **주중/주말/공휴일** 여부가 자동 판단되며, 리프트권과 리프트+렌탈권은 해당 기준에 맞는 가격표가 적용됩니다.
5. 좌측 카테고리 버튼으로 상품 그룹을 바꾼 뒤, POS 버튼처럼 상품 카드를 터치하면 1개씩 증가합니다.
6. 리프트+렌탈권은 `대인 / 학생 / 소인` 하위 탭이 표시되며, 탭별로 시간권 버튼이 달라집니다.
7. 우측 요약 영역에서 `+ / -` 버튼으로 수량을 즉시 조절하고, 총 합계를 확인합니다.
8. `초기화` 버튼으로 모든 선택을 한 번에 비울 수 있습니다.

### 요금 수정 & 공휴일 관리 페이지
1. `http://localhost:4000/pricing.html` 에 접속합니다. (계산기 페이지 상단의 **요금표 관리** 버튼으로 이동 가능)
2. 시즌 → 카테고리 → (필요 시) 하위 그룹을 선택 후 금액을 수정하세요. 주말 가격이 필요한 카테고리는 `주중 / 주말` 토글이 표시됩니다.
3. `공휴일 관리` 영역에서 날짜와 이름을 입력해 추가하거나, 목록에서 삭제할 수 있습니다. 공휴일은 자동으로 주말 요금이 적용됩니다.
4. `서버에 저장` 버튼을 누르면 가격표와 공휴일 목록이 모두 저장되어 서버 재시작 후에도 그대로 유지됩니다.
5. JSON 내보내기/불러오기, 클립보드 복사 기능으로 백업/복원이 가능합니다.

## 요금표 수정 가이드
- 모든 금액 정보는 `app.js` 의 `pricingData`(및 `liftPricing`) 객체에 모여 있습니다.
- 항목을 추가/삭제하거나 이름을 바꾸고 싶다면 `sharedCategories` 또는 각 시즌의 카테고리 배열을 수정하세요.
- 리프트권과 리프트+렌탈권은 `liftPricing` 의 `offSeason` / `peakSeason` 블록에 시간대별 금액을 입력하면 됩니다.
- 금액을 자주 바꾸는 경우, 향후 별도 설정 파일(JSON 등)로 분리하거나 관리자 UI를 붙일 수 있도록 구조를 단순화해 두었습니다.

## 향후 확장 아이디어
- 손님 정보/메모 입력 후 PDF 또는 영수증 프린터 출력
- 자주 쓰는 조합(패키지) 즐겨찾기 저장/불러오기
- 실시간 재고 또는 인원 현황 연동
- 목표 마진을 고려한 자동 할인/할증 로직

필요한 기능이 있으면 언제든지 알려주세요!
# 월드스키 강습보고서 시스템

## 설치 및 실행

### 1. 의존성 설치
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```

또는 개발 모드 (자동 재시작):
```bash
npm run dev
```

### 3. 웹사이트 접속
- 메인 페이지: http://localhost:3000
- 관리자 페이지: http://localhost:3000/admin
- 강사 페이지: http://localhost:3000/instructor
- 예약자 페이지: http://localhost:3000/parent
- 피드백 조회: http://localhost:3000/feedback-viewer

## 기능

### 강사 기능
- 강습 보고서 작성 및 제출
- 사진/동영상 업로드
- 자동 텍스트 생성

### 관리자 기능
- 강습 보고서 목록 조회
- 실시간 알림 (새 강습 제출 시)
- 보고서 상태 관리 (대기중/전송완료)
- 예약자에게 링크 전송
- SMS 전송 기능
- 강습 보고서 수정/삭제

### 예약자 기능
- 강습 보고서 조회
- 칭찬/건의 제출
- 구글 드라이브 사진/동영상 확인

## API 엔드포인트

### 강습 관리
- `GET /api/lessons` - 모든 강습 조회
- `POST /api/lessons` - 새 강습 추가
- `GET /api/lessons/:id` - 특정 강습 조회
- `PUT /api/lessons/:id` - 강습 수정
- `PUT /api/lessons/:id/status` - 강습 상태 변경
- `DELETE /api/lessons/:id` - 강습 삭제

### 피드백 관리
- `GET /api/feedback` - 모든 피드백 조회
- `POST /api/feedback` - 새 피드백 추가

### 기타
- `POST /api/upload-report` - 파일 업로드
- `POST /api/send-sms` - SMS 전송
